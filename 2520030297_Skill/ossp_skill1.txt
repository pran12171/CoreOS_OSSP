1. Linux VM, GCC, Git, Shell, and Makefile

* Set up and configure a Linux Virtual Machine (VM).
* Install and configure GCC for compiling and executing C programs.
* Initialize a Git repository to maintain and version-control the programs.
* Organize the work using a structured project directory.
* Learn the basic architecture of the Shell and understand how Linux commands are processed.
* Develop a simple Makefile and understand its role in automating program compilation.

2. Process Management and System Calls

* Study the concept of process abstraction in Linux.
* Use the `fork()` system call to create and manage child processes.
* Explore the `exec()` family of functions for replacing a process with a new program.
* Examine the relationship and interaction between parent and child processes.
* View and analyze the process hierarchy using commands such as `ps` and `pstree`.
* Perform system call tracing to observe how applications communicate with and request services from the Linux kernel.
